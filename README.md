# Match and Smash — public pages

Static Privacy Policy and Support pages for the App Store release of **Match and Smash**. There is intentionally no marketing home page.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `match-and-smash` under `progmesion`.
2. Upload the contents of this folder to the repository root.
3. On GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will publish the pages at:
   - `https://progmesion.github.io/match-and-smash/privacy.html`
   - `https://progmesion.github.io/match-and-smash/support.html`

Use those two final URLs in App Store Connect.

## Release note

This policy accurately describes the current no-ads version: it stores score and preferences locally, does not collect data, and has no advertising, analytics, or tracking. Update the policy and Apple App Privacy answers before adding any advertising or analytics SDK.
